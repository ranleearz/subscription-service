# Сервис учёта подписок

Приложение на [onno-framework](https://github.com/onno-erp/onno-framework): бизнес описан типизированной Java-метамоделью. Схему БД, REST API и веб-интерфейс фреймворк генерирует сам.

Клиент пополняет лицевой счёт платежами и оформляет подписку на один или несколько тарифов. Стоимость списывается при проведении документа; при нехватке денег проведение отклоняется. Отменённая подписка движений не создаёт.

## Запуск

Нужен JDK 21.

```bash
./gradlew bootRun
```

На Windows: `gradlew.bat bootRun`.

Откройте http://localhost:8080, логин `admin`, пароль `admin`.

При первом запуске создаются демо-клиенты, тарифы, платёж и проведённая подписка. База — `./data/subscriptions`. Чтобы начать заново, удалите папку `data`.

## Работа с приложением

1. Заведите **клиента** и **тариф**.
2. Создайте **платёж**, укажите клиента и сумму, нажмите **Провести** — деньги попадут на лицевой счёт.
3. Создайте **подписку** со строками (тариф и число периодов). Цена, суммы и дата окончания считаются при сохранении. Срок действия — дата начала плюс максимальный срок среди строк.
4. Проведите подписку. Если денег на счёте не хватает, проведение будет отклонено.
5. Остатки счетов и выручка по тарифам и клиентам — в разделе **Отчёты**.
6. Подписку можно **отменить** из списка или с формы, указав причину.

Регламентное задание переводит подписки в статусы «Активна» и «Истекла» по датам. Отменённые не изменяются.
